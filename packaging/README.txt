Logic Gate Simulator 1.0.0 - Windows x64

Extract the entire ZIP, then double-click LogicGateSimulator.exe.
Keep the assets folder next to the executable. No installation or compilation is needed.

Requires Windows 10/11 (64-bit) and a graphics driver supporting OpenGL 3.3.
The app uses an installed Windows font. No font or Visual C++ runtime installation is needed.

Project and source: https://github.com/JoaquimGon/Logic-Gates-Simulator
